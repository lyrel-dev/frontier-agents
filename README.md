## Architecture of the publication

`guides/*.md` is the canonical descriptive source. `tools/lesson_plan.py` is the curated speaking outline; each slide references canonical sections, which supply its speaker-note evidence. HTML and editable PowerPoint are generated by `tools/docs_build.py`. There are no separate competing capability or mechanism catalogs.

Read [coverage](guides/coverage.md), [editorial rules](EDITORIAL_STANDARD.md), [validation](VALIDATION.md), and [publishing](PUBLISHING.md). Older editions are retained only through Git history.

## Rebuild

```sh
python -m pip install -r tools/docs-requirements.txt
python -m playwright install chromium
python tools/docs_build.py
python tools/docs_check.py --browser
```

The build replaces only the prior documentation-owned files listed from a pinned Git baseline; it preserves the [separate readiness-console application](applications/aws-validation-console/README.md) and its workflow. No live AWS calls or external publication tasks are executed by this documentation build.
