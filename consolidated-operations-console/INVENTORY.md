## Reproduce the inventory

The manifest is a fixed source snapshot. To compare it with Git, enumerate the pinned tree and filter the exact directory shape, then compare paths and blob IDs. `git ls-tree -r -l` also provides stored byte sizes. This needs no AWS account or running prototype.

```bash
git ls-tree -r -l d926a81c584b6b69f41bfb9641532c4f8f2d7cb3 -- aws
git log d926a81c584b6b69f41bfb9641532c4f8f2d7cb3 --format='%H %aI %s' -- aws
```

The second command is scoped to `aws` because these eight commits contain the service analysis work; the manifest and file list apply the narrower `aws/<service>/analysis/**` filter. Historical-only paths remain separate from the active source set.
