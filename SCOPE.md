# Supported scope

This repository covers AWS DevOps Agent, AWS Security Agent and AWS FinOps Agent. Shared architecture material applies only to these three solutions. Implementation, merge and deployment handoffs are explicitly team-owned unless a retained product-specific capability says otherwise.

Git history is the version record. Do not retain snapshot directories, import payloads, distribution ZIPs or copied historical editions in the current tree. Current HTML, Markdown, source JSON and editable PowerPoint files are rebuilt from the retained source.

Product evidence is retained from the prior official-documentation review. This scope change is not a fresh external audit or live AWS test.
