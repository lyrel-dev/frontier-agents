# FIS and assessment diagram catalogue

## 1. Initial FIS model

The [five entity relationship diagrams](initial/README.md) cover native execution, definitions, selected targets, evidence/reports and application workload assessments. Read them with the [initial report](../docs/initial/report.md).

## 2. Suggested workflow model

The [three workflow diagrams](suggested/README.md) cover every identity-bearing entity, the important owned values and the local run lifecycle. Read them with the [suggested model](../docs/suggested/model.md).

Every diagram is available as an Obsidian Markdown note, editable Mermaid source and portable SVG. The notes embed the same Mermaid bytes as their canonical sources. Initial diagram renderings preserve the reviewed baseline; suggested diagram rendering is reproducible using the retained [diagram tooling](../docs/suggested/tools/README.md).
