# Common mechanism controls — mechanism reference speaker notes

All reference slides are untimed. Optional exercises are additional to the core programme.

## X-M01 — Name the storage boundary

Record whether context is local-machine, repository, Agent Space, individual agent or task-specific. Never infer a portfolio-wide store.

**Setup:** Select the relevant product mechanism. Record its scope, owner and activation setting. Run the proposed independent check using approved test inputs.

**Proposed verification:** Compare the configured boundary with independent evidence from the product or target.

**Boundary:** A common review process does not create a common runtime, credential set or approval model.
