Product resource models

The approved use cases describe objectives. This reference identifies the actual configuration, execution and evidence objects used to implement them. Follow a feature to its resource bindings, then inspect the relationship and lifecycle in the product guide. The model does not turn every concept into a creatable AWS resource.

DOC Documentation-defined conceptAWS AWS-defined resource or documented conceptEXT External system or engineering-owned artifact

Logical documentation model, not an AWS database schema, SDK payload or shared runtime. Green means AWS defines the concept; it does not mean every green item has an independent ARN, CRUD API or equal availability. Relationship multiplicities are qualified individually and are not service quotas.
