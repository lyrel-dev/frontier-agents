30-day pilot plan

Week 1: baseline

Choose one repo and one service. Measure PR turnaround, build triage, incident investigation time, and quality of outcomes. Check entitlements and permissions.

Week 2: developer pilot

Use Kiro for comprehension, bounded fixes, tests, IaC and documentation. Keep CI and peer-review gates.

Week 3: operations pilot

Connect DevOps Agent to selected telemetry, repositories and incidents. Compare agent investigations against source evidence.

Week 4: decision

Review time saved, false positives, rework, security posture and cost. Expand only validated workflows.

Implementation guardrails

Use least privilege, scoped integrations, approved data handling and human authorization for production changes. Require telemetry or test evidence for claims. Keep conventional tests, scanners and policy checks. AWS DevOps Agent production operations are GA; release management is preview. Amazon Q Developer IDE plugins have an announced end-of-support date of 30 April 2027, making Kiro a more forward-looking choice for new IDE rollouts.
