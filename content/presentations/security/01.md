1. A selected assessment uses application evidence, criteria and configured access.
2. Code review, design review, threat modeling and penetration testing are different operations.
3. The exposed model is assessment configuration and results—not a customer-configurable roster of DevOps agents.

<!-- block: b-3f414f091bb85cbdbdaa -->
## Presenter notes

<!-- block: b-3443b2e3cbb254c8a92e -->
Start with an application-security question and the kind of evidence that can answer it. Explain the assessment settings, criteria and context before discussing identifiers. A dynamic test needs a running target and identity; source and design reviews use different inputs and effects.
