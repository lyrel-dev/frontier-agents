1. An application Agent Space selects sources, configurations, users and assessment records.
2. Requirement packs and provider registration can be shared; application bindings remain specific.
3. Target scope, credentials and network access are separate configuration choices.

<!-- block: b-3dc5bad832e054bca5b9 -->
## Presenter notes

<!-- block: b-20e0d604fe765e079d19 -->
Do not equate this scope with a DevOps operational Agent Space. The diagram shows selected criteria; it does not place ownership of shared requirement packs inside the application. The detailed resource model specifies which objects are shared and which belong to the application.
