1. The request defines a cost question, period and analysis basis.
2. Authorized AWS data supplies observations; files and retained memory supply organizational context.
3. The result is an answer, analysis or artifact. An engineering or financial change is a separate decision.

## Presenter notes

<!-- block: b-0c40c27d5ca857619f60 -->
The labels deliberately differ from DevOps. Uploaded context files are not a native SKILL.md registry, and a requested task is not a custom-agent asset. Recommendation estimates come from their upstream services and must retain their provenance.
