1. Use the current investigation record and a declared observation cutoff.
2. State impact, evidence-supported findings, work in progress and unresolved reads.
3. Treat publication as a destination-specific effect; report time is not the measurement time.

<!-- block: b-dc27bd19c2625e1dba84 -->
## Presenter notes

<!-- block: b-16a3b08ab5c7504583e4 -->
The same investigation can supply an incident bulletin. Distinguish an update from a new diagnostic run. The output role and configured collaboration path influence delivery. A request for minute-resolution data does not establish a minute-by-minute custom-agent schedule or delivery guarantee.
